# Калькулятор
Сложение, вычитание, умножение и деление

# Требования
- PHP 7.4+

# Установка
composer require dmitriy-zhukov/my-test-library

# Использование
```php
$calculator = new Calculator();
echo $calculator->sum(-1, 3));  // 2
echo $calculator->subtract(5, 10));  // -5
echo $calculator->multiply(-12, 12));  // 144
echo $calculator->divide(10, 4));  // 2.5
```
